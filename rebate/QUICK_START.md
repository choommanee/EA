# ⚡ QUICK START GUIDE

## 🚀 5-Minute Setup

### Step 1: Copy Files (1 min)
```
Copy ทั้งหมดไป MT5:
📁 MQL5/Experts/ → RebateFarmPro.mq5
📁 MQL5/Include/ → *.mqh files
```

### Step 2: Compile (1 min)  
```
1. เปิด MetaEditor (F4)
2. เปิด RebateFarmPro.mq5
3. กด Compile (F7)
4. ตรวจสอบไม่มี Error
```

### Step 3: Setup EA (2 min)
```
1. Drag EA ลง Chart
2. ตั้งค่าพื้นฐาน:
   - TargetRebateDaily: 100
   - RebatePerLot: 5.0
   - LotSize: 0.5
   - MaxDailyLoss: 50
3. กด OK
```

### Step 4: Start Trading (1 min)
```
1. เปิด AutoTrading
2. ดู Dashboard เพื่อติดตาม
3. รอผลลัพธ์
```
